# 03 房间布局与机位

所有资产按这份布局设计尺寸，T01 按它建房间，T08 按标记点把资产放进去。坐标单位米，Z 朝上，-Y 是镜头一侧（房间前方开口）。

## 灯光

初始参数见 `config/style.json` 的 `lighting_initial`（7 盏灯，名字固定）。T01 调好后把最终值写进报告，T08 做整体统一调整。

## 代理模型（PROXIES 集合）

T01 在每个标记点放一个简单的灰色代理体（盒子或球），尺寸等于对应资产的大致包围盒，命名 `PROXY_XB`、`PROXY_GG`、`PROXY_ARM`、`PROXY_FC`、`PROXY_TV`。这样房间可以独立调光和构图。T08 组装时隐藏代理体，换成真实资产。
